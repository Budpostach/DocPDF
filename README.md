# DocGate PDF

**DocGate PDF** — локальний браузерний конвертер та оптимізатор документів для подання до **банківських і митних систем** (ДМСУ «Єдине вікно», валютний контроль банків, Вчасно, M.E.Doc, Клієнт-Банк) із двомовним інтерфейсом (**Українська / English**) та світлою/темною темою.

Усе зчитування, рендеринг, фільтрація зображень і формування PDF виконуються **виключно в пам’яті вашого браузера** — на сервер не передається жодного байта документів.

---

## Основні можливості

### Підтримувані формати та конвеєри обробки
- **PDF (`.pdf`)** → `PDF.js → Canvas → JPEG → jsPDF`  
  Розділяє багатосторінкові PDF на окремі сторінки або об’єднує та стискає документ в один файл під потрібний ліміт розміру.
- **Word (`.docx`, `.doc`, `.rtf`)** → `Word → векторний PDF (pdfmake) → PDF.js → JPEG → jsPDF`  
  - Напряму розбирає OOXML-структуру `.docx` (`JSZip`): колонтитули та вбудовані зображення/логотипи, таблиці з об’єднанням комірок (`colSpan` / `rowSpan`), рамками та заливками, табуляцію підписів, списки й кириличну типографіку (`Roboto` TTF) без спотворень і накладання тексту на межі таблиць.
  - Підтримує старі бінарні `.doc` (OLE2 / `cfb` із декодуванням `UTF-16LE` та `Windows-1251`), `.rtf` і HTML-документи Word.
- **Excel та таблиці (`.xlsx`, `.xls`, `.xlsm`, `.ods`, `.csv`)** → `Excel → векторний PDF (pdfmake) → PDF.js → JPEG → jsPDF`  
  - Зберігає пропорції стовпців, об’єднані комірки, рамки, кольори, вирівнювання, числові й датові формати (`ExcelJS` / `SheetJS`).
  - Емулює горизонтальне переповнення тексту в порожні сусідні комірки та автоматично підбирає масштаб кожного аркуша, щоб таблиця вміщувалася на **1 сторінку A4** без обрізання правого краю.

### Профілі та оптимізація під вимоги порталів
- **Швидкі профілі**:
  - **Митниця · ≤ 490 КБ** — посторінково, Grayscale.
  - **Банк (сторінки) · ≤ 1.9 МБ** — посторінково, колір.
  - **Банк (єдиний) · ≤ 4.5 МБ** — єдиний PDF, контрастний скан.
  - **Власні** — довільна комбінація ліміту (`490 КБ`, `950 КБ`, `1.9 МБ`, `4.5 МБ`), режиму виводу та кольору.
- **Адаптивний підбір DPI та якості JPEG**: автоматичний прохід за сіткою `300 → 50 DPI` і бінарний пошук якості (`0.90 → 0.12`), щоб кожна сторінка або об’єднаний файл впевнено вкладались у заданий ліміт.
- **Колірні режими**:
  - **Чорно-білий (Grayscale)** — максимальне зменшення ваги для митних декларацій та інвойсів.
  - **Контрастний скан** — підсилює чіткість тексту, печаток і підписів на білому фоні.
  - **Кольоровий** — зберігає оригінальну палітру документів.
- **Зручна робота з чергою**:
  - Пакетне додавання через drag-and-drop або вибір файлів, фільтрація (`Усі файли` / `У черзі` / `Готові`), живий пошук, перемикання вигляду (`Список` / `Плитка`).
  - Модальний перегляд готових сторінок (навігація клавішами `←`, `→`, `Esc`) та завантаження всіх результатів одним архівом `DocGate_PDF_Documents.zip`.
- **Сучасний мінімалістичний інтерфейс**:
  - Окремі сторінки для **Файлів**, **Вимог** та **Безпеки**.
  - Світла тема за замовчуванням із перемикачем на темну тему в шапці та збереженням вибору в `localStorage`.

## Технологічний стек

- **Інтерфейс**: React 19, TypeScript, Vite 8, Tailwind CSS v4, Lucide Icons
- **Шрифти**: Montserrat, Open Sans, JetBrains Mono
- **Обробка PDF і зображень**: `pdfjs-dist`, `jspdf`, `jszip`, `pdfmake`
- **Парсинг офісних документів**: `exceljs`, `xlsx`, `cfb`

## Структура проєкту

```text
├── public/
│   └── pdfjs/               # Локальні CMap-таблиці та стандартні шрифти PDF.js
├── src/
│   ├── components/          # Header, QueuePanel, SettingsPanel, PreviewModal, StandardsSection, Footer
│   ├── i18n/                # Локалізація інтерфейсу (UA / EN)
│   ├── services/
│   │   ├── pdfConverter.ts  # Єдиний цикл PDF.js → JPEG → jsPDF і керування DPI/якістю
│   │   ├── wordConverter.ts # Конвертація DOCX/DOC/RTF у проміжний векторний PDF
│   │   └── excelConverter.ts# Конвертація XLSX/XLS/ODS/CSV у проміжний векторний PDF
│   ├── types/               # TypeScript-інтерфейси черги та налаштувань
│   ├── App.tsx              # Стан черги, маршрутизація сторінок, перемикач теми та мови
│   └── index.css            # Конфігурація Tailwind CSS v4 та базових шрифтів
├── index.html
└── package.json
```

## Локальний запуск

### Вимоги
- Node.js `18+` (рекомендовано `20+`)

### Встановлення залежностей
```bash
npm install
```

### Змінні середовища (за потреби)
```bash
cp .env.example .env
```

### Режим розробки
```bash
npm run dev
```
Сервер розробки запускається за адресою `http://localhost:3000`.

### Перевірка типів і збірка для продакшену
```bash
npm run lint
npm run build
```
Готовий статичний бандл формується в директорії `dist/`.

---

## Розгортання

Проєкт збирається у повністю статичний бандл `dist/` (`npm run build`). Усі необхідні локальні ресурси `pdfjs-dist` (worker, CMap-таблиці та стандартні шрифти) розміщені в `public/pdfjs/`, тому застосунок готовий до розгортання без бекенду на **Vercel** або будь-якому статичному хостингу.
