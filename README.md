# PDF Converter for Banks & Customs / Конвертер PDF-документів для банків і митниці

Web application for converting and preparing PDF documents for banking and customs compliance with bilingual interface support (**Українська / English**).

## Features / Можливості

- PDF document conversion and formatting tailored for banking and customs requirements.
- Bilingual UI (**UA / EN**).
- Built with React, TypeScript, Vite, and Tailwind CSS.

## Getting Started / Запуск проєкту

### Prerequisites

- Node.js (v18+ recommended)

### Installation

```bash
npm install
```

### Environment Variables

Copy `.env.example` to `.env` and configure required variables before running locally.

### Development

```bash
npm run dev
```

The development server runs on `http://localhost:3000`.

### Build & Type Check

```bash
npm run lint
npm run build
```
